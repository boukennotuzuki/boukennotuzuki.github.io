# 冒険のつづき — GitHub Pages

岡崎市橋目町の飲食店「冒険のつづき」の公式サイト用ファイルです。

## 公開手順

1. GitHubで新しいRepositoryを作成
2. `index.html` をアップロード
3. `Settings` → `Pages`
4. `Deploy from a branch` → `main` → `/ (root)` を選択
5. 保存後、表示されたURLを確認

## 公開前に変更する場所

`index.html` 内の以下を実際のGitHub Pages URLへ変更してください。

- `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## 後から追加すると良い情報

- メニュー
- 営業時間
- 定休日
- 駐車場情報
- 店内写真
- 料理写真
- 予約方法
- Googleビジネスプロフィール
- 正確なGoogleマップ上の店舗URL
